# CQA Executive Dashboard (Prototype)

เปิดใช้งาน: https://suratmataphan12345-stack.github.io/cqa-executive-dashboard/

แดชบอร์ดต้นแบบสำหรับทีม CQA · หน้าแรก **QA Scorecard** ตาม Mockup ของ CQA · Requirement 33 ข้อ (QA_Dashboard_Requirements.xlsx) · 16 หัวข้อ · 74 KPI · ข้อมูลทั้งหมดเป็น Mock Data ตาม schema (seed ยอดรวมจากเอกสารอ้างอิง) ยังไม่ใช่ข้อมูลจริง

- Requirement ทั้ง 33 ข้อยัง "รอยืนยัน" — ดูค่าเริ่มต้นที่ต้นแบบใช้และคำถามที่ต้องยืนยันได้ที่หน้า **Requirement Tracker**
- เรื่องที่บันทึกผ่านฟอร์ม (Hot Issue · Award · Regulatory · ผล Audit) และสถานะ Requirement ในลิงก์นี้เก็บในเบราว์เซอร์ของแต่ละคน
